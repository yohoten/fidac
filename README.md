# 基于K-Means聚类与Prophet时序预测的重庆上市车企财务智能预警研究

## ——赛力斯外部协同经营模式对标长安自主研发模式

> 第六届重庆市大学生企业财务大数据智能决策应用赛 · 参赛作品

---

### 一、研究背景

重庆作为中国西部汽车工业重镇，拥有长安汽车(000625)和赛力斯(601127)两家代表性上市车企。两家企业在新能源汽车转型中采用了截然不同的发展路径：

| 维度                 | 赛力斯 (601127)          | 长安汽车 (000625)            |
| -------------------- | ------------------------ | ---------------------------- |
| **经营模式**   | 外部协同（华为智选）     | 自主研发（深蓝/阿维塔/启源） |
| **核心品牌**   | AITO问界 (2021起)        | 深蓝汽车、阿维塔、长安启源   |
| **研发路径**   | 联合研发（华为技术赋能） | 自主技术平台（SDA/EPA/CHN）  |
| **毛利率**     | ~29%（2025，高附加值）   | ~16%（2025，规模效应）       |
| **资产负债率** | ~71%（高杠杆扩张）       | ~60%（相对稳健）             |

**核心研究问题**：**"代工协同模式（赛力斯）和自主研发模式（长安），谁的财务风险更高、更不稳定？"**

---

### 二、研究框架

```
第一阶段：数据采集层
├── 8家A股车企 三大报表 (2016Q1-2025Q4)
├── 研发投入数据 (赛力斯/长安历年研发费用)
├── 赛力斯销量结构 (问界系列 vs 其他)
├── 长安销量结构 (深蓝/阿维塔/启源 vs 燃油及合资)
└── 行业对标数据 (乘联会月度销量)

第二阶段：智能决策模型层
├── Prophet 时序预测 → 预测未来6-12月财务指标走势
├── K-Means 聚类分析 → 8家车企分群，定位赛力斯/长安风险群
└── 孤立森林异常检测 → 识别财务异常信号

第三阶段：综合评价与对策
├── 财务健康度评分 (沃尔评分法)
├── 经营模式优劣对比
└── 行业对标建议
```

### 七、模型设计

| 模型     | 输入                    | 输出                    | 研究问题                    |
| -------- | ----------------------- | ----------------------- | --------------------------- |
| Prophet  | 季度财务指标(2016-2025) | 未来6-12月预测+置信区间 | 谁在"往下走"？              |
| K-Means  | 8家车企6维财务向量      | 聚类群组标签            | 赛力斯/长安各属哪个风险群？ |
| 孤立森林 | 全行业财务矩阵          | 异常指标标记            | 谁的异常信号更多？          |

---

### 八、预期结论

1. **模式对比**: 代工协同 vs 自主研制的财务稳定性差异
2. **风险识别**: Prophet趋势 + 孤立森林异常信号
3. **行业定位**: K-Means群组归属
4. **对策建议**: 针对两种模式的差异化风险管理建议
