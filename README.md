## 一、项目简介与研究背景

重庆作为中国西部汽车工业重镇，拥有**长安汽车（000625）**与**赛力斯（601127）**两家代表性上市车企。两家企业在新能源转型中采用截然不同的路径：

| 维度 | 赛力斯（601127） | 长安汽车（000625） |
| ---- | ---------------- | ------------------ |
| **经营模式** | 外部协同（华为智选） | 自主研发（深蓝/阿维塔/启源） |
| **核心品牌** | AITO 问界（2021 起） | 深蓝、阿维塔、长安启源 |
| **研发路径** | 联合研发（华为技术赋能） | 自主技术平台（SDA/EPA/CHN） |
| **毛利率（2025）** | ~29%（高附加值） | ~16%（规模效应） |
| **资产负债率（2025）** | ~71%（高杠杆扩张） | ~60%（相对稳健） |

本项目以 **8 家 A 股乘用车整车厂**为样本，用 K-Means 聚类、孤立森林、多模型时序预测（Ridge/Prophet/ARIMA/LSTM/三次指数平滑/线性回归）、杜邦分析、Z-score、沃尔评分等方法构建财务智能预警体系，重点剖析"外部协同 vs 自主研发"两种模式的财务风险差异。

## 六、模型与算法设计

| 模型 | 输入 | 输出 | 研究问题 |
| ---- | ---- | ---- | -------- |
| **Ridge 回归** | 季度财务指标（2016-2025） | 未来 4Q 预测 + 置信区间 + 残差 | 谁在"往下走"？ |
| **Prophet / ARIMA / LSTM / 三次指数平滑 / 线性回归** | 同 Ridge | 趋势预测（交叉验证） | 与 Ridge 对比 |
| **2026Q1 回测** | 训练剔除 2026Q1，预测 1 期 | MAE/sMAPE/MAPE/方向命中率 | 预测是否可靠？ |
| **K-Means** | 8 家车企 5 维风险向量 | K=3 聚类群组 | 各属哪个风险群？ |
| **孤立森林** | 同 K-Means 特征矩阵 | 异常得分 + 标签 | 谁的异常信号更多？ |
| **杜邦分析** | 利润表 + 资产负债表年报 | ROE 分解（净利率/周转率/杠杆，瀑布图） | 盈利驱动力差异 |
| **Z-score** | 财务分析指标年报 | Z 值 + 破产风险判定（行业阈值） | 是否存在破产风险？ |
| **沃尔评分** | 5 项预警指标 + 分档评分 | 百分制综合得分 | 财务预警综合排名 |
| **熵权法** | R²/sMAPE/σ 方法级指标 | 客观权重 + 综合分 | 客观赋权下最优模型 |

**沃尔评分体系（预警导向）**：毛利率 15 / 有息负债率 25（越接近 40% 越好）/ 流动比率 25（越接近 1.5 倍越好）/ 总资产周转率 15 / 营收增长率 20（分档评分，标准值 30%，消除天花板）。

**Z-score 新能源行业阈值**：危险 < 1.20 / 灰色 1.20-2.20 / 安全 > 2.20（传统制造业为 1.81 / 2.99）。

## 七、预测方法对比与权重方案

### 7.1 样本内 6 方法对比

6 种方法（Ridge/Prophet/ARIMA/LSTM/三次指数平滑/线性回归）在 赛力斯/长安 × 毛利率/资产负债率 4 个目标上做样本内对比。**Ridge 回归综合分样本内第一**（R² 优势显著）。

### 7.2 三种权重方案排名（误差指标改用 sMAPE）

熵权法定权（sMAPE 版）实测权重：**R² 42.9% / sMAPE 31.5% / σ 25.7%**。以 sMAPE 为误差指标的三方案统一排名（`score_methods`）：

| 方法 | 35/45/20 | 40/40/20 | 熵权 |
| ---- | -------- | -------- | ---- |
| Ridge回归 | 1 | 1 | 1 |
| 线性回归 | 2 | 2 | 2 |
| Prophet | 3 | 3 | 3 |
| ARIMA | 4 | 4 | 4 |
| LSTM | 5 | 5 | 5 |
| 三次指数平滑 | 6 | 6 | 6 |

> 说明：改用有界的 sMAPE 后，LSTM/三次指数平滑因毛利率近零产生的巨额 MAPE（2000%+）被封顶，排名更稳健；**Ridge 在三种方案下均第一**。

### 7.3 2026Q1 样本外一步前向回测

- **关键发现**：样本外排名与样本内相反——**LSTM/ARIMA 的 MAE 最低**（LSTM 0.041 / ARIMA 0.047），Ridge 仅第 5。综合分衡量的是**拟合优度**，不等于**预测精度**。
- **可预测性分化**：**资产负债率** MAPE<20%（LSTM/ARIMA 平均约 8.7%~9.2%），可直接用于预警；**毛利率** 2026Q1 近零（赛力斯 -0.46%、长安 -0.06%），MAPE 失去意义，仅作**方向判断**。
- **方向命中率**：Prophet/线性回归/三次指数平滑 0.75 最高，LSTM/ARIMA/Ridge 为 0.50。

## 八、主要结论

| 维度 | 赛力斯（代工协同） | 长安汽车（自主研发） |
| ---- | ------------------ | -------------------- |
| K-Means 聚类 | 稳健群 | 稳健群 |
| 孤立森林异常 | 正常（得分 0.166） | 正常（得分 0.160） |
| 沃尔评分（修正） | 第 1 名（90.4 分） | 第 5 名（78.4 分） |
| Z-score（新能源阈值） | 1.63（灰色区） | 1.82（安全区） |
| 杜邦 ROE（2023→2024） | -36.4% → 38.7%（净利率 +46.7pp 驱动） | 13.2% → 8.0%（净利率 -5.2pp 拖累） |
| 杜邦 ROE（2024→2025） | 38.7% → 15.0%（杠杆 -17.8pp 拖累） | 8.0% → 4.1%（净利率 -3.9pp 拖累） |
| 样本内预测最优 | Ridge 回归（综合分第一） | Ridge 回归 |
| 样本外回测最优 | LSTM / ARIMA（MAE 最低） | LSTM / ARIMA |
| 销量结构风险 | 高度集中（问界 ~95%） | 多品牌均衡（新能源 ~26%） |

**关键发现**：
1. 赛力斯沃尔评分高（营收增长突出），但 Z-score 落灰色区（高杠杆 + 问界集中风险）；2024 扭亏靠净利率、2025 回落靠杠杆去化。
2. 长安稳健但转型偏慢，近两年 ROE 连续由净利率拖累，规模效应滞后。
3. 样本内"Ridge 最优"不代表样本外精度最高——回测显示 LSTM/ARIMA 更优，需以回测为准。
4. 预测分层：资产负债率可精确预警，毛利率仅作方向判断。

## 十、误差指标与判定标准

| 指标 | 公式 | 特点 |
| ---- | ---- | ---- |
| MAPE | \|预测-实际\|/\|实际\|×100% | 实际近零时爆炸（无上界） |
| **sMAPE** | 200·\|预测-实际\|/(\|实际\|+\|预测\|) | **有界 0~200%**，跨指标平均稳健 |
| MAE | \|预测-实际\| | 绝对尺度，近零指标首选 |
| 方向命中率 | 实际/预测同号占比 | 近零突变时反映方向判断价值 |

**MAPE 判定（传统口径）**：<15% 有效 / 15-20% 偏差 / >20% 趋势中断。**本项目跨指标汇总以 sMAPE/MAE 为主、MAPE 为辅**。

## 十二、已知问题

1. **Prophet/CmdStan**：Windows 下需 `tbb.dll` 与 `prophet_model.bin` 同目录。若报 `code '3221225785'`，执行：
   ```bash
   copy ".venv\Lib\site-packages\prophet\stan_model\cmdstan-2.37.0\stan\lib\stan_math\lib\tbb\tbb.dll" ".venv\Lib\site-packages\prophet\stan_model\"
   ```
   Prophet 仅作对比验证，失败时 `compare_all_forecasts` 自动回退线性回归。
2. **小样本过拟合**：约 38 期样本下 LSTM/三次指数平滑样本外不稳定，三次指数平滑不建议作为主力模型。
3. **毛利率近零**：MAPE 无统计意义，务必用 MAE/sMAPE/方向命中率评估。
4. **单点回测局限**：2026Q1 仅一个时点，建议后续扩展为滚动窗口回测。
