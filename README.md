# 基于K-Means聚类与Prophet时序预测的重庆上市车企财务智能预警研究

## ——赛力斯外部协同经营模式对标长安自主研发模式

> 第六届重庆市大学生企业财务大数据智能决策应用赛 · 参赛作品

---

### 一、研究背景

重庆作为中国西部汽车工业重镇，拥有长安汽车(000625)和赛力斯(601127)两家代表性上市车企。两家企业在新能源汽车转型中采用了截然不同的发展路径：

| 维度                 | 赛力斯 (601127)          | 长安汽车 (000625)            |
| -------------------- | ------------------------ | ---------------------------- |
| **经营模式**   | 外部协同（华为智选）     | 自主研发（深蓝/阿维塔/启源） |
| **核心品牌**   | AITO问界 (2021起)        | 深蓝汽车、阿维塔、长安启源   |
| **研发路径**   | 联合研发（华为技术赋能） | 自主技术平台（SDA/EPA/CHN）  |
| **毛利率**     | ~29%（2025，高附加值）   | ~16%（2025，规模效应）       |
| **资产负债率** | ~71%（高杠杆扩张）       | ~60%（相对稳健）             |

**核心研究问题**：**"代工协同模式（赛力斯）和自主研发模式（长安），谁的财务风险更高、更不稳定？"**

### 八、模型设计

| 模型                | 输入                         | 输出                               | 研究问题                     |
| ------------------- | ---------------------------- | ---------------------------------- | ---------------------------- |
| **Ridge回归** | 季度财务指标(2016-2025)      | 未来4Q预测 + 置信区间 + 残差诊断   | 谁在"往下走"？               |
| Prophet(对比)       | 季度财务指标(2016-2025)      | 趋势方向验证（cap/floor约束）      | 与Ridge回归对比验证          |
| **MAPE 回测** | Ridge预测值 + 2026Q1实际值 | MAPE(%) + 有效性判定               | 预测是否可靠？行业是否突变？ |
| K-Means             | 8家车企5维财务向量           | K=3 聚类群组标签                   | 赛力斯/长安各属哪个风险群？  |
| 孤立森林            | 同 K-Means 特征矩阵          | 异常得分 + 标签                    | 谁的异常信号更多？           |
| 杜邦分析            | 利润表 + 资产负债表年报      | ROE 因素分解（净利率/周转率/杠杆） | 盈利驱动力差异               |

| **雷达图**    | 5维指标（与K-Means对齐）     | 极坐标对比 + 行业均值线            | 赛力斯 vs 长安 风险全貌      |

### 九、沃尔评分修正体系

| 指标               | 权重 | 标准值 | 评价方向   | K-Means对应   |
| ------------------ | ---- | ------ | ---------- | ------------- |
| 毛利率             | 15分 | 15%    | 越高越好   | 毛利率     |
| 有息负债率         | 25分 | 40%    | 越接近越好 | 有息负债率 |
| 流动比率           | 25分 | 1.5倍  | 越接近越好 | —            |
| 总资产周转率       | 15分 | 0.8次  | 越高越好   | —            |
| 营业收入同比增长率 | 20分 | **30%**    | **分档评分**   | —            |

> **修正说明**：
> - 营收增长率标准值从 15% 上调至 30%（行业平均水平）
> - 采用分档评分：`<15%: 实际/标准 | 15-50%: 1+(实际-15%)/35% | >50%: 2+min(实际-50%,50%)/50%`
> - 关系比率上限从 [0,2] 放宽到 [0,3]，消除天花板效应

### 十、Z-score 行业阈值适配

| 行业 | 危险区 | 灰色区 | 安全区 |
|------|--------|--------|--------|
| 传统制造业 | < 1.81 | 1.81-2.99 | > 2.99 |
| **新能源车企** | **< 1.20** | **1.20-2.20** | **> 2.20** |

> 理由：新能源车企普遍高研发投入、轻资产运营、高增长特征，传统制造业阈值过严

### 十一、MAPE 误差判定标准

| 平均 MAPE         | 判定        | 含义                                               |
| ----------------- | ----------- | -------------------------------------------------- |
| **< 15%**   | 有效     | 模型对近期趋势捕捉有效，预测具有参考价值           |
| **15%-20%** | 偏差   | 预测存在一定偏差，建议结合定性分析使用             |
| **> 20%**   | 趋势中断 | 行业可能发生突变（如价格战加剧），预测仅作方向参考 |

### 十三、模型初步结论

| 维度                | 赛力斯 (代工协同)              | 长安汽车 (自主研发)      |
| ------------------- | ------------------------------ | ------------------------ |
| K-Means 聚类        | 群0（稳健群）               | 群0（稳健群）         |
| 孤立森林异常        | 正常（得分 0.166）             | 正常（得分 0.160）       |
| 沃尔评分排名（修正） | 第1名 (90.4分)             | 第5名 (78.4分)          |
| Z-score（新能源阈值） | 1.63（灰色区）          | 1.82（安全区）       |
| 毛利率趋势          | 下降（Ridge预测）          | 上升                  |
| 资产负债率趋势      | 上升（~76%→82%）           | 上升（~58%→60%）     |
| 销量结构风险        | **高度集中**（问界~95%） | 多品牌均衡（新能源~26%） |
| **MAPE 评估** | 待2026Q1实际数据               | 待2026Q1实际数据         |

> **Z-score 阈值说明**：新能源车企采用危险<1.2/灰色1.2-2.2/安全>2.2（传统制造业为1.81/2.99）

**关键发现**：

1. 赛力斯沃尔评分虽高（营收增长突出），但 Z-score 落入灰色区（高杠杆 + 集中风险）
2. 长安汽车稳健但转型缓慢，沃尔评分排名中等
3. 两种模式各有优势与风险，需差异化对策建议
4. 六种预测方法中 Ridge回归 综合表现最优，Prophet仅做对比验证
